# UtterScope

**語学学習者のための、ローカルファーストな発話分析ツール。**

UtterScopeは、録音された会話や語学レッスンを分析するためのオープンソースCLIツールです。

音声ファイルを渡すだけで、会話の文字起こし、話者の識別、学習者の発話の抽出を行い、発話時間・発話速度・ポーズ・フィラーなどの指標を算出します。音声処理は可能な限りローカル環境で完結します。

```bash id="r04lqy"
utterscope analyze lesson.mp3
```

## なぜUtterScope？

スピーキング練習の成果を測ることは簡単ではありません。

英会話レッスンが終わった後、「いくつかの表現で詰まった」といった感覚は残っていても、次のような問いに客観的に答えるのは困難です。

* 実際に自分はどのくらい話していたのか？
* 1か月前より速く話せるようになったか？
* ポーズや沈黙は減っているか？
* どのフィラーを使いすぎているか？
* 一度の発話を以前より長く続けられるようになったか？
* どの表現や文法パターンで繰り返し詰まっているか？

UtterScopeは録音された会話を構造化されたデータへ変換し、スピーキング能力の変化を継続的に観察できるようにします。

## 機能

### ローカル文字起こし

ローカルハードウェア向けに最適化されたWhisperベースの音声認識を利用して、音声をローカルで文字起こしします。

レッスンの生音声を外部の文字起こしサービスへアップロードする必要はありません。

### 話者分離

UtterScopeは会話内の話者を分離し、そのうち学習者に属する発話を識別します。

```text id="9ld9ak"
講師      00:17  What do you think about living in a small apartment?

学習者    00:22  I think... it is a little narrow, so I feel pressure.

講師      00:29  I see. What would you change about it?
```

### スピーキング指標

UtterScopeは文字起こし結果と音声から、決定論的に計算できる指標を算出します。

例えば次のような指標です。

* 発話時間
* 発話割合
* 1分あたりの単語数（WPM）
* 平均発話長
* ターン数
* ポーズの頻度
* 長いポーズ
* フィラーの頻度

これらの指標の算出にLLMは必要ありません。

### オプションの言語分析

必要に応じてLLMによる、より高度な分析を利用できます。

例えば、

* 文法上の問題
* 不自然な表現
* 語彙の提案
* より自然な代替表現
* 繰り返し発生しているミス

などを分析できます。

基本的な文字起こしと定量分析は、LLMを利用しなくても実行できます。

### レポート

解析結果は、機械処理しやすい構造化データと、人間が読みやすいレポートの両方として出力できます。

```text id="6gox64"
lesson.mp3
    │
    ▼
UtterScope
    │
    ├── transcript.json
    ├── analysis.json
    ├── feedback.json   # optional (--llm)
    └── report.html
```

## インストール

> UtterScopeは現在開発中です。

リポジトリをcloneします。

```bash id="pypkeg"
git clone <repository-url>
cd utterscope
```

[uv]を利用して依存関係をインストールします。

```bash id="nqq1ow"
uv sync
```

UtterScopeを実行します。

```bash id="2nq6m6"
uv run utterscope analyze path/to/lesson.mp3
```

初回は対話セットアップでトークンを保存できます（話者分離用の Hugging Face トークン、LLM 用の Gemini API キー）。

```bash
uv run utterscope setup
```

`GEMINI_API_KEY` が無い場合は `--no-llm` を付けるか、デフォルトの `--llm` 実行時にエラーになります。

## 使い方

引数なしで起動すると対話フローになります（音声パス → ASR モデル → 分析 →
学習者選択 → 任意で LLM プロバイダー / モデル）:

```bash
utterscope
```

またはフラグ付きで録音レッスンを分析します。話者が複数いる場合は、○/● の選択 UI で学習者を選びます。

```bash id="wnt6fp"
utterscope analyze lesson.mp3
```

学習者をあらかじめ指定して対話選択をスキップします。

```bash
utterscope analyze lesson.mp3 --learner SPEAKER_01
```

使用するASRモデルを指定します。

```bash id="5ky9v9"
utterscope analyze lesson.mp3 --model large-v3-turbo
```

長いポーズとみなす秒数を変更します（CLI が最優先。未指定時は `.env` / setup の値、なければ 1.0）。

```bash
utterscope analyze lesson.mp3 --long-pause-threshold 1.5
```

`utterscope setup` でも同じ閾値を `.env` の `UTTERSCOPE_LONG_PAUSE_THRESHOLD` として保存できます。

LLMによる分析を使用せずに実行します。

```bash id="v3k7e4"
utterscope analyze lesson.mp3 --no-llm
```

解析結果の出力先を指定します。

```bash id="eqt32b"
utterscope analyze lesson.mp3 --output ./results
```

出力例:

```text
./results/
├── transcript.json   # 話者付き文字起こし
├── analysis.json     # 学習者の発話指標（時間・WPM・ポーズ・フィラーなど）
└── feedback.json     # 任意の LLM フィードバック（--llm）
```

## アーキテクチャ

UtterScopeは主にPythonで実装します。

現在想定している技術スタックは次のとおりです。

| コンポーネント       | 技術                    |
| ------------- | --------------------- |
| CLI           | Typer + Rich          |
| パッケージ管理       | uv                    |
| データモデル        | Pydantic              |
| 音声処理          | FFmpeg                |
| 発話区間検出        | Silero VAD            |
| 音声認識          | MLX Whisper / Whisper |
| 話者分離          | pyannote.audio        |

主要な推論コンポーネントについては、将来的に異なるバックエンドへ交換できる設計を目指します。

## 設計原則

### Local First

音声には多くの個人的な情報が含まれます。

そのためUtterScopeでは、文字起こし・話者分離・定量分析を可能な限りユーザーのローカル環境で実行することを目指します。

### 測定できるものは決定論的に

直接測定できるものをLLMに計算させる必要はありません。

発話時間、WPM、ポーズ時間、フィラー頻度などの指標は、通常のプログラムによって決定論的に計算します。

LLMは意味理解が必要な処理に限定して利用します。

### Backend Agnostic

音声認識や言語分析を、特定のモデルやサービスへ永続的に依存させません。

長期的には、次のようなバックエンドを交換可能にすることを目指します。

* ローカルWhisper実装
* その他のASRモデル
* ローカルLLM
* クラウドLLM API

### CLI First

UtterScopeは、まずCLIアプリケーションとして設計します。

Webサーバーを起動したりJavaScriptフロントエンドをインストールしたりしなくても、コアとなる解析パイプラインを利用できることを重視します。

## プライバシー

UtterScopeは、生の音声データをユーザーのマシン内に保持することを前提として設計します。

一部のオプション機能では外部APIを利用する場合があります。その場合、外部サービスへ送信されるデータは、選択したプロバイダーと設定によって異なります。

外部へのデータ送信を明示的かつオプションにすることを目指します。
